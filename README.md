# ICS-Vista

Abstract: Industrial Control System (ICS) and Operational Technology (OT) networks run the infrastructure behind power, water, and manufacturing systems, yet most organizations cannot say with confidence what devices are actually connected to them. These networks contain legacy controllers that cannot tolerate active scanning, so unmanaged engineering laptops, vendor equipment, and forgotten devices routinely go undetected, creating a growing blind spot in the attack surface.
This project proposes **ICS-Vista**, a platform that discovers and classifies OT/ICS devices entirely by observing network traffic, without sending any packets to the devices themselves. Traffic is captured passively from a mirrored network port and decoded across major industrial protocols — Modbus, DNP3, S7comm, EtherNet/IP, and OPC UA — to identify every communicating device and extract its identity, protocol usage, and communication behavior. Each device is then assigned a functional role within the Purdue Reference Model — field controller, supervisory system, or engineering workstation — based on how it communicates, not on manual configuration.                                                                                                                                                                                                        The system will be evaluated using publicly available ICS network traffic datasets to measure how many real devices it correctly discovers, how accurately it classifies each device's Purdue-level role, how many false alerts it produces, and how well it performs as traffic volume increases. The expected outcome is a working prototype that demonstrates passive, protocol-aware asset discovery and role classification can be achieved accurately and safely, using an architecture capable of scaling toward the kind of continuous, production-level visibility that real OT security teams need.  this is going to be the final abstract of my project
